UI-тестирование

В данном проекте были написаны автотесты для сервиса Stellar Burgers. Это космический фастфуд: можно собрать и заказать бургер из необычных ингредиентов.
Тесты были написаны для следующих функций
Регистрация:
1. Проверка успешной регистрации. Поле «Имя» должно быть не пустым; в поле Email введён email в формате логин@домен: например, 123@ya.ru. Минимальный пароль — шесть символов.
2. Проверка вывода ошибки для некорректного пароля.
Вход:
3. Проверка входа по кнопке «Войти в аккаунт» на главной.
4. Проверка входа через кнопку «Личный кабинет».
5. Проверка входа через кнопку в форме регистрации.
6. Проверка входа через кнопку в форме восстановления пароля.
Переход в личный кабинет:
7. Проверка перехода по клику на «Личный кабинет».
8. Проверка перехода из личного кабинета в конструктор.
9. Проверка перехода по клику на «Конструктор» и на логотип Stellar Burgers.
Выход из аккаунта:
10. Проверка выхода по кнопке «Выйти» в личном кабинете.
Раздел «Конструктор»:
Проверка, что работают переходы к разделам:
11. «Булки»,
12. «Соусы»,
13. «Начинки».

Дополнительно:
Была реализована функция которая генерирует email и пароль.
